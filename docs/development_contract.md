## 第一条 合作内容与研发范围

本项目的开发成果为**云南星势力航空科技有限公司官方系统（含前台展示端、后台管理端及微信自动化导入接口）**。系统基于 Next.js 16 / React 19 / Prisma / SQLite 技术栈构建，采用响应式布局与极具视觉冲击力的暗色玻璃拟态（Glassmorphism）设计。

具体的系统功能模块及技术规范如下：

### 1. 前台展示端系统功能
* **1.1 首页 (Homepage)**
  * 搭载具有三维视觉呼吸缩放（Ken Burns Effect）的 Hero 级大图轮播组件（`HomeHeroCarousel`），文字配备多级交错（Staggered）淡入动画。
  * 鼠标悬停智能暂停机制，支持大尺寸高对比度交互箭头及胶囊指示器导航。
  * 首页底部数据指标展示条（Data Strip）支持从后台动态读取展示（如培训学员数量、客户满意度等），拒绝硬编码。
  * 融合高可用灾备逻辑：当 SQLite 数据库遭遇死锁或读取异常时，首页 0.1 毫秒内自动回退至默认黄金备份大图，保障系统 100% 可用性。
* **1.2 关于我们 (About Us)**
  * 动态展示公司介绍、企业使命与核心团队信息，支持模块大图及富文本布局。
  * 集成关于页专用的 4 项核心数据指标可视化面板，由后台直接配置和更新。
* **1.3 公司动态列表及详情页 (News Section)**
  * 采用服务端物理分页（`skip-take` 机制）的动态列表，减轻数据库检索负载，提升渲染速度。
  * 全站文章数据默认按发布时间降序倒序排列，保证新内容秒级置顶。
  * 动态详情页支持纯文本、排版配图以及原微信公众号文章直达链接。
* **1.4 无人机维修课程模块 (UAV Maintenance Courses)**
  * 支持展示专业无人机维修课程，包含课程分类、时长、价格及核心优势描述。
  * 支持列表服务端物理分页，并支持独立的课程详细介绍页展示。
* **1.5 风采展示画廊 (Showcase Gallery)**
  * 支持类目（Category）在客户端零延迟无刷新过滤与秒速切换。
  * 内置艺术级磨砂玻璃拟态 Lightbox 大图灯箱浏览器，支持左右滑动切换、高对比度文字投影投影遮罩，提供极佳的沉浸式看图体验。
* **1.6 项目合作板块 (Project Cooperation)**
  * 集中展示与各航空院所及合作单位的协同项目，支持合作伙伴名称、项目简介及服务类型字段展示，采用物理分页。
* **1.7 联系我们与诉求提交 (Contact Us)**
  * 嵌入轻量级、防空值提交的反馈表单（包含姓名、联系电话、电子邮箱、合作诉求及文字描述）。
  * 表单直接对接 SQLite 数据库底层，写入成功后给予优雅的无刷新动画反馈。
* **1.8 全局即时智能模糊检索系统 (Global Search)**
  * 导航栏内置具有磨砂微粒质感的可视化搜索入口，支持快捷键 `ESC` 一键唤醒与关闭。
  * 编写跨表并行检索 API（`/api/search`），支持一次性对课程、动态、项目合作、风采展示四个核心 SQLite 数据表进行并行异步检索。
  * 搜索结果以高发光度的胶囊气泡（如 `📚 课程`、`📰 动态` 等）进行分类展示，配备即时 Loading 指示器。

### 2. 后台管理系统功能 (Admin Portal - `/admin`)
* **2.1 安全凭证认证机制 (Authentication)**
  * 采用企业级 `NextAuth.js` 与哈希加盐算法 `bcryptjs` 确保管理员账户的会话安全，防护未授权越权访问。
  * 支持管理员密码的可视化修改（带有密码强度与二次确认逻辑）。
* **2.2 全局基本配置管理 (System Config)**
  * 提供可视化的网站全局配置（如网站名称、ICP 备案号、底部版权等）。
  * 深度集成首页四大指标、关于页四大指标的数值及标签的表单化配置，支持一键热更新前台。
* **2.3 首页轮播图可视化管理 (Hero Carousel Management)**
  * 提供完整的轮播图增删改查（CRUD）管理，可配置一级标题、二级标题、背景图 URL、跳转链接和排序优先级。
* **2.4 微信公众号文章同步管理系统 (WeChat Auto-Importer)**
  * 独创**公众号自动同步参数配置面板**：支持可视化录入微信 AppID、AppSecret（支持安全密码遮蔽）、Token 及加密密钥。
  * 微信内容提取 API：编写并发布了 `/api/wechat/sync` 预留接口，支持微信文章链接的一键导入。
  * **防盗链多媒体镜像系统**：底层通过 cURL 和子进程机制，强力抓取微信原始图片，并自动下载并物理保存至本地 `/public/wx-images/` 目录下，彻底解决微信防盗链“破图/404”的问题，自动将抓取的文章落库至“公司动态”。
* **2.5 公司动态/课程管理/风采展示/项目合作 CRUD 模块**
  * 全线引入基于 `AdminBatchTable` 的数据表格，内置“全选/反选”功能。
  * 包含红底二次安全确认的**批量删除（Batch Delete）系统**，防止误删，支持对内容、封面、类别和排序号的可视化维护。
* **2.6 联系表单诉求审批 (Contact Requests Inbox)**
  * 集中展示前台用户提交的合作或维修申请，支持按“待处理（PENDING）”、“处理中（PROCESSING）”、“已完成（COMPLETED）”状态进行跟踪管理。

### 3. 系统技术规格与基础架构
* **前台框架**：React 19.2 + Next.js 16.2 (App Router & Server Actions)
* **后端支撑**：Node.js 20+ Runtime
* **数据库层**：Prisma ORM 5.15 + SQLite 关系型数据库
* **样式系统**：CSS Custom Properties (Variables) 全手写，拒绝冗余第三方 CSS 框架，确保加载性能。
* **部署运维**：Nginx 反向代理（配置强制 HTTPS，Let's Encrypt 证书由 Certbot 定时任务全自动续签） + PM2 进程级高可用集群守护。
